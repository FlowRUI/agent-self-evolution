# Agent Self-Evolution

[English](./README.md)

这是一个从长程 Agent 轨迹中提炼可复用 Skill 的脱敏设计案例。公开仓库只包含 Markdown，不包含实现代码、雇主代码、内部数据、生产提示词或保密指标。

核心流程为：证据定位 → 失败归因 → 知识提取 → Skill 提案 → 确定性验证 → 人工审查。

## 设计原则

- 先证据、后结论：每条诊断都引用轨迹事件 ID。
- 只生成提案，不静默修改线上 Skill。
- 使用 Schema、引用完整性和安全规则进行确定性校验。
- Demo 仅使用可复现的合成轨迹。

本项目为独立编写的教育性设计文档，重点展示系统边界、可审查性和工程思考，而非复刻任何专有系统。实现代码有意保持私有。
